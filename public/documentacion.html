Volver

Duan

Protección anti bots basada en comportamiento. Detecta y bloquea tráfico automatizado mediante desafíos de arrastre y análisis de comportamiento.

Inicio rápido: Generá tus claves en el panel, agregá el widget a tu sitio y verificá desde tu backend.

Instalación

1. Agregar el widget

Insertá esto en tu HTML donde quieras que aparezca el captcha:

<div 
  class="duan-widget-container" 
  data-sitekey="TU_SITE_KEY"
  data-callback="onVerify">
</div>

<script src="https://tu-app.onrender.com/duan-widget.js"></script>

2. Callback opcional

Podés definir una función JavaScript que se ejecute al verificar:

<script>
function onVerify(token) {
  console.log("Token:", token);
  // Enviar al backend para validar
}
</script>

3. Validar en backend

Desde tu servidor, verificá el token recibido:

const response = await fetch(
  "https://duan-detect.onrender.com/api/duan/siteverify", 
  {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      token: req.body["duan-response"],
      secret: "TU_SECRET_KEY"
    })
  }
);

const data = await response.json();

if (data.success) {
  // Usuario verificado
} else {
  // Bloquear acceso
}

API

POST /api/keys

Genera nuevas credenciales (site key + secret key).

// Respuesta
{
  "siteKey": "duan_site_abc123...",
  "secretKey": "duan_secret_xyz789..."
}

POST /api/duan/siteverify

Verifica un token de desafío completado.

// Request body
{
  "token": "duan_token_abc...",
  "secret": "duan_secret_xyz..."
}

// Respuesta exitosa
{
  "success": true,
  "verified": true
}

// Respuesta fallida
{
  "success": false,
  "verified": false,
  "error": "token_invalido"
}

POST /api/duan/precheck

Verificación previa sin desafío visual. Analiza comportamiento del usuario.

// Respuesta frictionless
{
  "success": true,
  "frictionless": true,
  "token": "duan_token_..."
}

GET /api/duan/challenge

Obtiene un desafío de arrastre cuando el precheck no es suficiente.

Configuración del widget

Atributo Descripción
data-sitekey Tu site key pública (requerido)
data-callback Función JavaScript a ejecutar al verificar

Seguridad

  • Secret key: Nunca la expongas en el frontend. Solo se usa en backend.
  • Tokens únicos: Cada token es de un solo uso y expira automáticamente.
  • Análisis de comportamiento: Detecta movimientos de mouse, tiempo en página, WebDriver, y más.
  • Rate limiting: Bloquea direcciones IP con múltiples intentos fallidos.

Ejemplos por lenguaje

Node.js (Express)

app.post('/formulario', async (req, res) => {
  const token = req.body['duan-response'];
  
  const r = await fetch(
    'https://duan-detect.onrender.com/api/duan/siteverify', 
    {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        token,
        secret: process.env.DUAN_SECRET
      })
    }
  );
  
  const { success } = await r.json();
  
  if (!success) {
    return res.status(403).send('Verificación fallida');
  }
  
  // Procesar formulario
});
