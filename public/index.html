段 Duan

Verificación anti-bots por rompecabezas: el visitante arrastra una pieza gris hasta encajarla, y de fondo se analizan movimiento, tiempos y conexión para distinguir humanos de bots.

Demo en vivo

1. Conseguí tu site key

Guardá la secret key ahora — no se vuelve a mostrar. Las llaves viven en memoria del servidor, así que si el servicio se reinicia se pierden (ver README para persistencia).

2. Poné el widget en tu página

<div class="duan-widget-container" data-sitekey="TU_SITE_KEY"></div>
<script src="https://tu-app.onrender.com/duan-widget.js" async defer></script>

Al verificarse, el widget crea un input oculto duan-response dentro del <form> más cercano, con el token. Se envía junto con el resto del formulario.

3. Validá el token en tu backend

// en tu servidor, al recibir el formulario
const r = await fetch("https://tu-app.onrender.com/api/duan/siteverify", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    token: req.body["duan-response"],
    secret: "TU_SECRET_KEY"
  })
});
const { success } = await r.json();
if (!success) return res.status(403).json({ error: "verificación fallida" });
