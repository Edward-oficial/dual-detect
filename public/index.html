Guía de integración
PasoInstrucción
1 Insertá el widget en la página que querés proteger, usando la site key generada arriba. 
<div class="duan-widget-container" data-sitekey="TU_SITE_KEY"></div>
<script src="https://tu-app.onrender.com/duan-widget.js" async defer></script>

Al verificarse, se crea un input oculto duan-response dentro del <form> más cercano.
2 En tu backend, al recibir el formulario, validá el token contra Duan usando tu secret key. 
const r = await fetch("https://tu-app.onrender.com/api/duan/siteverify", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    token: req.body["duan-response"],
    secret: "TU_SECRET_KEY"
  })
});
const { success } = await r.json();
3 Si success es false, rechazá el envío antes de procesar el resto de la lógica. 
if (!success) return res.status(403).json({ error: "verificación fallida" });
